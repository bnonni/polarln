# polarln documentation

To start, read [CLI](cli.md) for the `polarln` command, or [SDK](sdk.md) for the TypeScript methods.

## Usage

- [CLI](cli.md): install and run the `polarln` command, the flags, the backends, the help, the output, and the usage errors.
- [Command reference](commands/README.md): one page for each of the 49 commands, with the usage, the flags, the backends, the SDK method, and an example.
- [SDK](sdk.md): use polarln as a TypeScript library, with the backends, the methods, `getNodeCredentials`, and `listTools`.
- [Errors](errors.md): the error format, and the codes of the bridge, the tools, the Docker backend, and the CLI.

## Backends

- [Docker backend](docker-backend.md): run the Polar tools on Docker without the Polar app, with the data folder, the networks file, and the node kinds.
- [Polar app](polar-app.md): the Polar app check, the Polar app together with polarln, changes outside polarln, and the bridge port.
